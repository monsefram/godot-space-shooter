# godot-space-shooter

**FR** — Petit jeu de tir spatial **2D** (*space shooter*) développé avec **Godot 4 (GDScript)** : vaisseau du joueur, tirs de projectiles et boucle de jeu.

**EN** — A small **2D** space-shooter game built with **Godot 4 (GDScript)**: player ship, projectile firing and game loop.

---

## Concepts / Highlights

- **FR**
  - Contrôle du joueur (`player.gd`) et système de projectiles (`projectile.gd` / `projectile.tscn`).
  - Scène principale (`main.tscn`) orchestrant la boucle de jeu.
- **EN**
  - Player control (`player.gd`) and projectile system (`projectile.gd` / `projectile.tscn`).
  - Main scene (`main.tscn`) orchestrating the game loop.

## Stack

Godot 4 · GDScript.

## Lancement / Run

**FR** : ouvrir le projet dans **Godot 4**, puis lancer `main.tscn` (F5).
**EN**: open the project in **Godot 4**, then run `main.tscn` (F5).
